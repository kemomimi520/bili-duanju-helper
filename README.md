> **当前版本号 [v1.0.1](https://github.com/kemomimi520/bili-duanju-helper/releases/tag/v1.0.1)，已在哔哩哔哩 9.19.0 多部短剧小程序及多分辨率机型上实机测试通过，其他版本或机型尚未大规模验证。**

本项目用于在 Android 设备上自动完成哔哩哔哩（B站）短剧小程序的**剧集遍历**与**激励广告解锁**。

通过 Android 标准无障碍服务（`AccessibilityService`）模拟人工浏览与触控操作，在观看前一次性自动刷完当前短剧的锁集广告并解锁全集，到达最后一集后自动停止。本应用独立运行，不修改哔哩哔哩客户端，无需 Root 权限，未申请网络权限。

---

## 主要功能

- **全集自动遍历与快进检测**：
  - 自动解析当前短剧的集数进度（如 `选集(1/38)`），按顺序逐集检测。
  - 进入新一集后自动将进度条快进至约 `78%`，立即触发试看锁或中段广告锁，已解锁剧集约 2～3 秒即可跳过。
  - 检测完成后自动翻至下一集，并在确认最后一集无锁后自动停止。
- **多类型激励广告处理**：
  - **常规倒计时广告**：等待界面出现奖励达成提示后自动点击关闭。
  - **互动体验任务广告**：识别“前往体验 10 秒可获得奖励”类弹窗，自动进入体验页并在停留满设定时长后返回；若遇到小游戏实名认证等阻塞弹窗，自动点击关闭按钮退出。
  - **额外奖励与挽留弹窗**：自动识别解锁后弹出的“额外赠送多集（观看领奖励）”弹窗及“继续观看领取奖励”挽留提示。
- **防误触付费与多级外部跳转拉回**：
  - 内置付费关键词黑名单，自动跳过 `免广告解锁`、`开通会员`、`漫币/B币购买` 等按钮；若弹出 `选择解锁方式` 付费弹窗，先自动关闭再点免费看广告入口。
  - 针对部分机型外部应用独立任务栈及多品牌系统跳转确认框，采用**系统返回 -> 最近任务切回 -> Intent 唤醒**三级拉回策略，避免外部体验后或误跳转后卡死在第三方应用。
- **可控悬浮胶囊交互（v1.0.1 优化）**：
  - 支持在胶囊任意区域（含操作按钮）长按拖动调节位置并自动记忆坐标。
  - 默认仅在哔哩哔哩前台界面显示，切出至桌面或其他应用时自动隐藏。
  - 胶囊右侧提供显式 **`×`** 关闭按钮，点击可立即关闭悬浮窗并停止运行，无需撤销系统无障碍权限；应用首页另提供一键 **「关闭悬浮窗并退出无障碍服务」** 按钮。

## 实现原理

本工具不涉及反编译、进程注入、Hook 或网络抓包，完全基于 Android 系统公开的无障碍接口工作：

1. **控件树与物理屏幕坐标适配**：通过 `AccessibilityService` 读取聚焦窗口控件节点，并基于物理屏幕尺寸（`WindowMetrics` / `getRealMetrics`）校验界面元素，避免 Android 11～16 状态栏/导航栏高度差导致误判，目标窗口开启 `FLAG_SECURE` 时仍可正常识别。
2. **手势与事件调度**：通过 `performAction` 与 `dispatchGesture` 模拟点击、进度条横向拖动与列表翻页；拖动区域自动避开系统左右边缘返回手势热区。
3. **无障碍悬浮控制**：使用 `TYPE_ACCESSIBILITY_OVERLAY` 绘制悬浮胶囊，无需额外申请悬浮窗权限，默认按前台包名显隐并支持随时关闭，不做后台常驻保活。

## 使用方法

### 1. 下载与安装

前往 [Releases 页面](https://github.com/kemomimi520/bili-duanju-helper/releases/latest) 下载最新 APK 并安装。

### 2. 开启无障碍权限

1. 打开 **B站短剧自动看广告插件（无障碍版）**，点击 **「1. 前往开启无障碍权限」**。
2. 在系统无障碍服务列表中找到本服务并开启。
   - **Android 13 及以上版本提示**：若侧载安装后系统提示“受限制的设置”导致开关置灰，先点击应用内的 **「打开本应用信息 -> 允许受限制设置」**（在应用信息页右上角菜单中启用），再返回开启无障碍开关。

### 3. 开始与停止

1. 打开哔哩哔哩，进入任意短剧小程序播放页（底部可见选集进度，如 `选集(1/38)`），侧边悬浮胶囊会自动出现。
2. 点击胶囊上的 **`▶ 刷广告`** 启动自动任务，按住胶囊任意位置可拖动调整位置。
3. 刷完最后一集会自动停止；随时点击 **`⏹ 停止`** 中止任务，或点击右侧 **`×`** 按钮隐藏悬浮窗；若需彻底退出，可在插件主界面点击 **「关闭悬浮窗并退出无障碍服务」**。

## 参数配置

应用主界面提供以下可调参数（默认参数已满足大多数场景）：

| 参数 | 默认值 | 说明 |
| :--- | :---: | :--- |
| 快进进度条检测广告 | 开启 | 切集后直接快进至 `78%` 触发试看锁与中段广告锁 |
| 拦截自动跳出/商店下载 | 开启 | 非体验任务期间自动拒绝外部跳转确认弹窗或拉回原应用 |
| 启用无障碍悬浮控制胶囊 | 开启 | 总开关，关闭后立即隐藏悬浮窗 |
| 仅在哔哩哔哩内显示悬浮窗 | 开启 | 离开哔哩哔哩时自动隐藏悬浮窗（点击胶囊 `×` 亦可手动隐藏） |
| 外部软件体验停留秒数 | `11` 秒 | “体验 10 秒领奖励”任务的停留时长（可调范围 `5~30` 秒） |
| 快进后等待锁弹出毫秒数 | `900` ms | 拖动进度条后等待锁集界面渲染的时间（弱网可调至 `1200~1600` ms） |
| 单个广告最大等待秒数 | `45` 秒 | 单个广告超时后的兜底退出阈值 |

## 本地构建

环境要求：JDK 17+、Android SDK (API 34)。

```bash
# 克隆仓库
git clone https://github.com/kemomimi520/bili-duanju-helper.git
cd bili-duanju-helper

# 运行核心状态机单元测试
./gradlew :core:test

# 构建 Debug APK
./gradlew :app-accessibility:assembleDebug
```

构建产物路径：`app-accessibility/build/outputs/apk/debug/app-accessibility-debug.apk`。
