# BiliDramaHelper — B站短剧全集自动看广告解锁助手（无障碍免 Root 版）

一款轻量、纯净、**零软件修改**的 Android 端自动化辅助工具，基于 Android 官方标准无障碍服务（`AccessibilityService`）模拟正常用户的屏幕阅读与触控手势，帮助用户在观看哔哩哔哩（B站）短剧小程序时自动完成剧集巡航与激励广告观看解锁，解放双手。

---

## ✨ 核心特性

- **100% 纯净无侵入（免 Root / 零改包 / 零联网权限）**
  - 完全运行于独立的无障碍服务进程，**不修改、不注入、不 Hook 任何第三方软件代码或内存，不拦截/篡改任何网络数据包**。
  - 应用清单**未申请 `INTERNET` 网络权限与存储读写权限**，所有状态判断均在本地离线完成，无任何隐私数据上传。
- **纯控件树识别（零截屏 / 零 OCR / 无视 `FLAG_SECURE`）**
  - 直接解析 Android 无障碍节点树（原生 View + WebView / Compose 虚拟无障碍节点），无需屏幕截图、无需图像识别或外部大模型，即使短剧播放器开启 `FLAG_SECURE` 防截屏保护依然稳定工作。
- **极速单段探锁与防跳集巡航**
  - 针对短剧播放器进度条（相对位移手势模型）深度适配：切集后等待缓冲就绪，单次快进至约 `78%` 即可同时触发**试看结束锁**与**中段暂停广告锁**，已解锁剧集巡航仅需约 **2.3～2.5 秒/集**。
  - 自动避开 Android 全面屏左右边缘返回手势热区（`>=14%` 安全内缩），彻底杜绝快进时误触系统返回键。
- **全形态激励广告与防误触付费保护**
  - **支持多种广告任务形态**：普通倒计时激励视频、挽留弹窗（自动点“继续观看领取奖励”）、WebView 额外赠送多集福利弹窗（“观看领奖励”）、以及“去体验 10 秒即可获得奖励”站内/站外互动广告（自动计时体验并在达标后返回关闭，遇到小游戏防沉迷/实名阻塞弹窗自动点 `×` 退回）。
  - **严格防付费误触黑名单**：自动识别并绕过 `免广告解锁`、`开通会员`、`漫币/B币购买`、`选择解锁方式` 等付费按钮与充值抽屉，仅点击免费看广告解锁入口。
  - **反自动跳出与应用商店拦截**：普通倒计时广告期间若触发误跳转或应用商店/安装器拉起，自动拒绝弹窗或拉回继续广告计时；用户主动回桌面（Launcher）时则安静暂停不抢焦点。
- **随用随开，大结局自动停机**
  - 通过轻量无障碍悬浮胶囊（`TYPE_ACCESSIBILITY_OVERLAY`，免额外悬浮窗权限，兼容 Android 8.0 ～ Android 16）手动点击 `▶ 刷广告` 启动、`⏹ 停止` 结束；巡航至最后一集（如 `38/38`）验证无锁后自动停机，不做 24 小时后台常驻保活。

## 📱 使用方法

1. 安装 `app-accessibility-debug.apk`（或自行编译 Release 包）。
2. 打开 **B站短剧自动看广告插件（无障碍版）**：
   - 点击 **「1. 前往开启无障碍权限」**，在系统无障碍列表中开启本服务。
   - *Android 13 / 14 / 15 / 16 提示*：若侧载安装后系统提示“受限制的设置（开关置灰）”，先点击插件内的 **「打开本应用信息 -> 允许受限制设置」**（在应用详情页右上角 `⋮` 菜单中勾选允许），再返回开启无障碍开关即可。
3. 打开哔哩哔哩，进入任意短剧小程序播放页（看到选集进度如 `选集(1/38)`）。
4. 点击屏幕侧边的粉色悬浮胶囊 **`▶ 刷广告`** 即可开始全集自动检测与看广告解锁；随时再次点击胶囊 **`⏹ 停止`** 可立即停机。

## ⚙️ 参数说明

| 参数项 | 默认值 | 说明 |
| :--- | :---: | :--- |
| 快进进度条检测广告 | 开启 | 进入剧集后自动快进至约 `78%` 立即试探试看锁/中段锁 |
| 拦截自动跳出/商店下载并拉回 | 开启 | 非互动任务期间自动拒绝外部跳转弹窗及应用商店拉起 |
| 跳转外部软件体验停留秒数 | `11` 秒 | 针对“前往体验 10 秒获得奖励”广告任务的停留时长（范围 `5~30s`） |
| 快进进度条后等待锁弹出毫秒数 | `900` ms | 快进后观察锁集浮层弹出的等待窗口（弱网环境可适当调大至 `1200~1600ms`） |
| 单个广告最大等待秒数 | `45` 秒 | 单支激励广告超时兜底返回阈值 |

## 🛠️ 本地编译与测试

环境要求：**JDK 17+**、**Android SDK (API 34)**。

```bash
# 运行核心状态机与规则匹配单元测试
./gradlew :core:test

# 编译无障碍版 APK
./gradlew :app-accessibility:assembleDebug
```

编译产物路径：`app-accessibility/build/outputs/apk/debug/app-accessibility-debug.apk`。

## 📂 工程结构

- `:core`：纯 Kotlin 跨端核心状态机（`DramaStateEngine`）、节点规则匹配器（`RuleMatcher`）、集数解析器（`EpisodeParser`）与完备单元测试集（`DramaEngineTest`）。
- `:app-accessibility`：Android 官方 `AccessibilityService` 实现、无障碍节点扫描器（`NodeScanner`）与 `TYPE_ACCESSIBILITY_OVERLAY` 悬浮控制器（`FloatingController`）。
