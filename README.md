> **当前版本号 [v1.0.4](https://github.com/kemomimi520/bili-duanju-helper/releases/tag/v1.0.4)，已在 Android 16 真机及哔哩哔哩 9.19.0 新剧真实外部跳转广告（淘宝等，关闭“后台弹出界面”权限）与多桌面切换场景下实测通过。**

本项目用于在 Android 设备上自动完成哔哩哔哩（B站）短剧小程序的**剧集遍历**与**激励广告解锁**。

通过 Android 标准无障碍服务（`AccessibilityService`）模拟浏览与触控操作，在观看前自动刷完当前短剧的锁集广告并解锁全集，到达最后一集后自动停止。本应用独立运行，不修改哔哩哔哩客户端，无需 Root 权限，未申请网络权限。

---

## 主要功能

- **全集自动遍历与快进检测**：
  - 自动解析当前短剧集数进度（如 `选集(1/40)`），按顺序逐集检测。
  - 进入新一集后自动将进度条快进至约 `78%`，触发试看锁或中段广告锁；已解锁剧集自动跳过。
  - 切集过渡与同容器加载期间自动等待，避免误触发返回键导致退出短剧小程序；确认最后一集无锁后自动停止。
- **跨 ROM 外跳广告识别与最近任务拉回**：
  - 精准匹配 `前往10秒即可获得奖励` / `跳转X秒可获得奖励` 等外跳体验任务弹窗并触发体验跳转；若目标应用未安装而跳转至应用商店详情页，被动停留满时长不点安装后再拉回领奖。
  - 针对部分厂商限制后台弹出界面的情况，采用通用三级切回策略（系统返回 -> 三模式最近任务卡片识别 / 双击最近任务 -> Intent 唤醒），区分小程序短剧任务卡片（如小程序标题 / 剧名）与主应用卡片，快速关闭中途拦截的 `AdWebActivity` / `AdCallUp` 弹窗并回到激励广告页领奖。
- **独立可控的悬浮胶囊生命周期与运行防冻结保护**：
  - 支持在胶囊任意区域拖动调节位置并记忆坐标；默认仅在哔哩哔哩前台显示，切换至其他应用时自动隐身。
  - 当插件主程序从后台多任务列表被划掉或关闭时，立即停止运行并彻底移除悬浮窗及占位视图，避免在其他应用或回到哔哩哔哩后继续弹窗；重新打开插件主界面即可恢复显示。
  - 批刷激活期间临时提升无障碍服务为 `specialUse` 前台运行状态以防止系统冻结（如 MIUI/HyperOS `GreezeManager`、ColorOS `Hans`、OriginOS 墓碑机制）中断计时，停止批刷后立即解除；支持识别「点击按钮即可获得奖励」Compose 跳转弹窗及「再看一个激励视频，额外赠送」WebView 奖励弹窗。
  - 胶囊右侧提供 **`×`** 关闭按钮，主界面提供 **「关闭悬浮窗并退出无障碍服务」** 按钮。

## 实现原理

本工具不涉及反编译、进程注入、Hook 或网络抓包，完全基于 Android 系统公开的无障碍接口工作：

1. **窗口过滤与控件识别**：通过 `AccessibilityService` 仅读取真实应用窗口（`TYPE_APPLICATION`）及系统跳转确认框，过滤系统手势条、侧边栏、灵动岛等系统叠加层干扰；结合屏幕物理尺寸校验节点坐标，兼容 `FLAG_SECURE` 防截屏页面。
2. **手势调度与防误退**：通过 `performAction` 与 `dispatchGesture` 模拟点击、进度条横向拖动与列表翻页；拉回后对 `AdWebActivity` 等广告页内落地页优先关闭而不误退短剧容器。
3. **随主程序生命周期联动**：结合 `onTaskRemoved()` 与 `ActivityManager.appTasks` 状态同步，在跨 ROM 后台划掉主程序时即时销毁无障碍悬浮窗口。

## 使用方法

### 1. 下载与安装

前往 [Releases 页面](https://github.com/kemomimi520/bili-duanju-helper/releases/latest) 下载最新 APK 并安装。

### 2. 开启无障碍权限

1. 打开 **B站短剧自动看广告插件（无障碍版）**，点击 **「1. 前往开启无障碍权限」**。
2. 在系统无障碍服务列表中找到本服务并开启。
   - **Android 13 及以上版本提示**：若侧载安装后系统提示“受限制的设置”导致开关置灰，先点击应用内的 **「打开本应用信息 -> 允许受限制设置」**（在应用信息页右上角菜单中启用），再返回开启无障碍开关。

### 3. 开始与停止

1. 点击 **「2. 打开哔哩哔哩」**，进入任意短剧小程序播放页，侧边悬浮胶囊会自动出现。
2. 点击胶囊上的 **`▶ 刷广告`** 启动自动解锁；按住胶囊任意位置可拖动调整位置。
3. 到达最后一集会自动停止；点击 **`⏹ 停止`** 可中止运行；点击 **`×`** 或从后台划掉本插件主程序即可关闭悬浮窗（重新打开插件主程序可再次显示）。

## 参数配置

| 参数 | 默认值 | 说明 |
| :--- | :---: | :--- |
| 快进进度条检测广告 | 开启 | 切集后快进至 `78%` 触发试看锁与中段广告锁 |
| 拦截自动跳出/商店下载 | 开启 | 外部体验跳转满时长后自动拉回继续广告计时 |
| 启用无障碍悬浮控制胶囊 | 开启 | 总开关，关闭后立即销毁悬浮窗 |
| 仅在哔哩哔哩内显示悬浮窗 | 开启 | 离开哔哩哔哩时自动隐藏 |
| 外部软件体验停留秒数 | `11` 秒 | 外跳体验任务的停留时长（可调范围 `5~30` 秒） |
| 快进后等待锁弹出毫秒数 | `900` ms | 拖动进度条后等待锁集弹窗渲染的时间 |
| 单个广告最大等待秒数 | `45` 秒 | 单个广告超时后的兜底退出阈值 |

## 本地构建

环境要求：JDK 17+、Android SDK (API 34)。

```bash
git clone https://github.com/kemomimi520/bili-duanju-helper.git
cd bili-duanju-helper

./gradlew :core:test
./gradlew :app-accessibility:assembleDebug
```

构建产物路径：`app-accessibility/build/outputs/apk/debug/app-accessibility-debug.apk`。
