# B站短剧自动刷广告解锁助手（免 Root 无障碍版）

> **一句话说明**：看 B 站短剧不想每看一集就被广告打断？打开一部短剧后点一下悬浮球，它会**自动把整部剧的所有广告提前刷完、全集解锁**，刷到最后一集自动停止，之后你就可以一口气无广告连看全集。

📥 **直接下载安装包**：前往 [Releases 页面下载最新版 APK](https://github.com/kemomimi520/bili-duanju-helper/releases/latest)

## 🎯 主要作用

- **提前刷完全集广告**：从第 1 集自动刷到最后一集，遇到未解锁的集数自动看广告解锁，已解锁的快速跳过（约 2～3 秒/集）。
- **解放双手，刷完自动停**：不用盯着屏幕点关闭、不用手动上滑下一集，刷完大结局自动停止。
- **不改软件、绝不误花钱**：只通过安卓自带的「无障碍服务」模拟手指操作，**不修改 B 站、不需要 Root、没有联网权限**；严格跳过“免广告解锁 / 开通会员 / 漫币购买”等付费按钮，只点免费的看广告解锁。

## 📱 怎么用（3 步上手）

### 第 1 步：安装并开启无障碍权限
1. 下载安装 [最新版 APK](https://github.com/kemomimi520/bili-duanju-helper/releases/latest)。
2. 打开本应用，点击 **「1. 前往开启无障碍权限」**，在系统无障碍列表里找到并开启本插件。
   - **安卓 13 ～ 16 提示**：如果系统提示「受限制的设置」导致开关点不了，先回到本应用点 **「打开本应用信息 -> 允许受限制设置」**（在应用详情页右上角 `⋮` 菜单中点允许），再回去开无障碍即可。

### 第 2 步：进入你想看的 B 站短剧
打开哔哩哔哩，正常点进任意短剧小程序播放页（底部能看到类似 `选集(1/38)` 的进度即可）。

### 第 3 步：一键开始，挂机等它刷完
1. 点击屏幕侧边的粉色悬浮胶囊 **`▶ 刷广告`**，插件会自动开始从当前集往后刷。
2. 刷到最后一集会自动停止；中途随时点 **`⏹ 停止`** 即可立刻停下，回桌面也会自动暂停不抢屏幕。

## 💡 能处理哪些情况？

- **倒计时视频广告**：自动等倒计时出现「已获得奖励」后立刻点关闭。
- **“去体验 10 秒获得奖励”广告**：自动点击进入体验页，倒计时满 11 秒自动返回领奖；遇到小游戏实名弹窗会自动点 `×` 退出。
- **额外赠送多集弹窗**（如“再看一个广告额外送 2 集”）：自动点击「观看领奖励」一并领完。
- **广告乱跳应用商店 / 自动跳出**：自动点取消或直接拉回 B 站继续计时。
- **付费弹窗拦截**：遇到「免广告解锁」「选择解锁方式（会员/漫币）」自动跳过或关掉，绝不误触发付款。

## 🔧 实现原理（大白话版）

本工具 **没有破解 B 站，也没有修改任何软件**，原理就是利用 Android 官方的 `AccessibilityService`（无障碍服务）替你自动操作手机：

1. **看界面**：只读取当前屏幕上控件的文字和位置（**不截屏、不做图像识别**，就算短剧防截屏也能正常工作）。
2. **快进试探**：切到新一集后，模拟手指把进度条拉到约 `78%` 的位置——如果这一集需要看广告，B 站的试看锁或中段广告锁会立刻弹出来，不用傻等视频播放。
3. **自动看广告并翻页**：识别到免费解锁按钮就模拟点击 -> 等屏幕出现「已获得奖励」就点关闭 -> 解锁完成后模拟上滑进入下一集，循环直到最后一集自动结束。

## ⚙️ 参数说明（默认即可，一般不用改）

| 设置项 | 默认值 | 什么时候需要调？ |
| :--- | :---: | :--- |
| 快进进度条检测广告 | 开启 | 建议保持开启，可省去每集漫长的试看等待 |
| 拦截自动跳出/商店下载 | 开启 | 防止广告乱跳出导致倒计时中断 |
| 外部体验停留秒数 | `11` 秒 | 遇到“体验 10 秒领奖”偶尔提示时长不足时，可改大到 `12~13` 秒 |
| 快进后等待锁弹出时间 | `900` ms | 网速特别慢、锁弹窗加载慢时，可调大到 `1200~1600` ms |
| 单个广告最大等待秒数 | `45` 秒 | 遇到卡死广告的兜底退出时间 |

## 🛠️ 自己编译（开发者可选）

环境要求：JDK 17+、Android SDK (API 34)。

```bash
# 运行单元测试
./gradlew :core:test

# 编译无障碍版 APK
./gradlew :app-accessibility:assembleDebug
```

产物位于：`app-accessibility/build/outputs/apk/debug/app-accessibility-debug.apk`。
