> **当前版本号 [v1.0.0](https://github.com/kemomimi520/bili-duanju-helper/releases/tag/v1.0.0)，已在哔哩哔哩 9.19.0 多部短剧小程序上实机测试通过，其他版本或机型尚未大规模验证。**

本项目用于在 Android 设备上自动完成哔哩哔哩（B站）短剧小程序的**剧集遍历**与**激励广告解锁**。

通过 Android 标准无障碍服务（`AccessibilityService`）模拟人工浏览与触控操作，在观看前一次性自动刷完当前短剧的锁集广告并解锁全集，到达最后一集后自动停止。本应用独立运行，不修改哔哩哔哩客户端，无需 Root 权限，未申请网络权限。

---

## 主要功能

- **全集自动遍历与快进检测**：
  - 自动解析当前短剧的集数进度（如 `选集(1/38)`），按顺序逐集检测。
  - 进入新一集后自动将进度条快进至约 `78%`，立即触发试看锁或中段广告锁，已解锁剧集约 2～3 秒即可跳过。
  - 检测完成后自动翻至下一集，并在确认最后一集无锁后自动停止。
- **多类型激励广告处理**：
  - **常规倒计时广告**：等待界面出现奖励达成提示后自动点击关闭。
  - **互动体验任务广告**：识别“前往体验 10 秒可获得奖励”类弹窗，自动进入体验页并在停留满设定时长后返回关闭；若遇到小游戏实名认证等非可取消弹窗，自动点击弹窗关闭按钮退出。
  - **额外奖励弹窗**：识别解锁后弹出的“额外赠送多集（观看领奖励）”弹窗并自动完成观看。
  - **挽留弹窗处理**：遇到“放弃机会 / 继续观看领取奖励”提示时自动选择继续观看。
- **防误触付费与跳转保护**：
  - 内置付费关键词黑名单，自动跳过 `免广告解锁`、`开通会员`、`漫币/B币购买` 等按钮；若界面已弹出 `选择解锁方式` 付费弹窗，先自动关闭后再点击看广告解锁入口。
  - 广告正常计时期间若触发应用商店重定向或非预期外部跳转，自动取消弹窗或返回哔哩哔哩继续计时；用户手动切换至桌面时自动暂停，不抢占前台。

## 实现原理

本工具不涉及反编译、进程注入、Hook 或网络抓包，完全基于 Android 系统公开的无障碍接口工作：

1. **控件树识别（零截屏 / 零 OCR）**：通过 `AccessibilityService` 读取当前活动窗口的控件节点（文本、资源 ID 与坐标），无需截屏与图像识别，目标窗口开启 `FLAG_SECURE` 防截屏保护时仍可正常识别。
2. **手势与事件调度**：通过 `performAction` 与 `dispatchGesture` 模拟人工点击、进度条横向拖动与列表翻页；拖动区域自动避开系统左右边缘返回手势热区。
3. **无障碍悬浮控制**：使用 `TYPE_ACCESSIBILITY_OVERLAY` 绘制悬浮启停胶囊，无需额外申请悬浮窗权限，点击手动启动/停止，不进行后台常驻保活。

## 使用方法

### 1. 下载与安装

前往 [Releases 页面](https://github.com/kemomimi520/bili-duanju-helper/releases/latest) 下载最新 APK 并安装。

### 2. 开启无障碍权限

1. 打开 **B站短剧自动看广告插件（无障碍版）**，点击 **「1. 前往开启无障碍权限」**。
2. 在系统无障碍服务列表中找到本服务并开启。
   - **Android 13 及以上版本提示**：若侧载安装后系统提示“受限制的设置”导致开关置灰，请先点击应用内的 **「打开本应用信息 -> 允许受限制设置」**（在应用信息页右上角菜单中启用），再返回开启无障碍开关。

### 3. 开始自动解锁

1. 打开哔哩哔哩，进入任意短剧小程序播放页（底部可见选集进度，如 `选集(1/38)`）。
2. 点击屏幕侧边悬浮胶囊上的 **`▶ 刷广告`** 启动自动任务。
3. 刷完最后一集后会自动停止；运行期间随时点击 **`⏹ 停止`** 可手动中止。

## 参数配置

应用主界面提供以下可调参数（默认参数已满足大多数场景）：

| 参数 | 默认值 | 说明 |
| :--- | :---: | :--- |
| 快进进度条检测广告 | 开启 | 切集后直接快进至 `78%` 触发试看锁与中段广告锁 |
| 拦截自动跳出/商店下载 | 开启 | 非体验任务期间自动拒绝外部跳转确认弹窗或拉回原应用 |
| 显示无障碍悬浮控制胶囊 | 开启 | 控制是否显示侧边悬浮启停按钮 |
| 外部软件体验停留秒数 | `11` 秒 | “体验 10 秒领奖励”任务的停留时长（可调范围 `5~30` 秒） |
| 快进后等待锁弹出毫秒数 | `900` ms | 拖动进度条后等待锁集界面渲染的时间（弱网可调至 `1200~1600` ms） |
| 单个广告最大等待秒数 | `45` 秒 | 单个广告超时后的兜底退出阈值 |

## 本地构建

环境要求：JDK 17+、Android SDK (API 34)。

```bash
# 克隆仓库
git clone https://github.com/kemomimi520/bili-duanju-helper.git
cd bili-duanju-helper

# 运行核心状态机单元测试
./gradlew :core:test

# 构建 Debug APK
./gradlew :app-accessibility:assembleDebug
```

构建产物路径：`app-accessibility/build/outputs/apk/debug/app-accessibility-debug.apk`。
